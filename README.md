# Linux System Information Reporter

## Project Overview
A Bash scripting project that automates Linux system information collection and generates timestamped system reports.

## Features
- Collects current user information
- Displays system hostname
- Detects Linux distribution and kernel version
- Reports system uptime and load average
- Collects CPU information
- Monitors RAM and swap usage
- Checks disk utilization
- Displays network interfaces and routing information
- Identifies currently logged-in users
- Generates timestamped text reports

## Technologies
- Ubuntu Linux
- Bash Scripting
- WSL2

## Commands Practiced
`whoami`, `hostname`, `uname`, `uptime`, `lscpu`, `free`, `df`, `ip`, `who`, `grep`, `tee`, `chmod`.

## How to Run

Clone the repository:

https://github.com/ABDULLAH576-code/linux-system-information-reporter.git
Navigate into the project:

```bash
cd linux-system-information-reporter
```

Give execution permission:

```bash
chmod +x server-info.sh
```

Execute:

```bash
./server-info.sh
```

The generated report will be saved inside the `reports/` directory.
